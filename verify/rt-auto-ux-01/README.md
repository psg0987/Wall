## 패치가 바꾸는 동작 (base main 대비, probe 로그 근거)

1. **새 지배 판정이 모든 경로로 확대**: 예전에는 플레이어 매매 경로(`afterCtl`)에서만 '새로 지배한 회사 자동 경영'(S.apAll)이 켜졌고 결정은 다음 결산까지 미뤄졌다. 이제 `ctlAll()`이 지배권이 새로 'P'가 된 모든 회사(직접·간접, 공개매수·합병·다른 주주 매도로 저절로 생긴 지배 포함)에 대해 S.apAll이면 ON, ON이면 그 자리에서 `autop` 1회.
2. **설립 회사(G.fdGo)도 '새 지배'로 잡힘** — S.apAll ON일 때 설립 직후 자동 경영이 켜지고 `autop`가 설립 프리셋을 덮어씀: 예) IT 프리셋 0(성장 0.2, R&D 2) → 성장 0.04, R&D 0 (base: ap 0, 프리셋 유지). S.apAll OFF면 base와 같음. **패치 설명('기존 결정 보존')과 다른 의미 있는 차이 — 수정하지 않고 보고.**
3. **수동 OFF 회사가 지배권을 잃었다 되찾으면** S.apAll ON일 때 다시 ON(+즉시 결정). 예전에도 플레이어 매수 경로에서는 같았으나(afterCtl), 이제 모든 경로에서 같다. 지배를 유지하는 동안의 수동 OFF는 그대로(P3).
4. 플레이어가 지배하지 않거나, 자동 경영을 0일째 직접 켠 경우(S.apAll OFF)의 360일 게임 상태는 base와 바이트 단위로 같다(P7a·P7b 해시 일치). S.apAll ON에서 setOwn 경로로 얻은 지배는 차이가 난다(P7c, 의도된 변경 1).
